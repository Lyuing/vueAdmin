## 测试场景

### 1. RSA加密登录流程测试

#### 测试步骤
1. 打开浏览器访问前端应用
2. 进入登录页面
3. 输入用户名和密码
4. 点击登录按钮

#### 预期结果
- 前端自动获取RSA公钥
- 密码使用RSA加密后发送到后端
- 后端成功解密密码并验证
- 返回包含token、用户信息、权限和菜单的响应
- 前端存储token和用户信息
- 自动跳转到主页

#### 验证点
- 检查浏览器控制台，确认没有错误
- 检查Network标签，验证：
  - `/api/rsa/public-key` 返回真实的RSA公钥
  - `/api/auth/signin` 请求包含加密的密码和clientId
  - 响应格式为 `{code: 0, data: {...}, message: "success"}`
- 检查LocalStorage，确认token和userInfo已保存

### 2. 用户会话恢复测试

#### 测试步骤
1. 登录成功后，刷新页面
2. 观察页面加载过程

#### 预期结果
- 页面刷新后自动恢复登录状态
- 调用 `/api/users/v1/me` 获取最新用户信息
- 动态路由和菜单正确加载
- 不需要重新登录

#### 验证点
- 检查Network标签，确认调用了 `/api/users/v1/me`
- 响应包含最新的用户信息、权限和菜单
- 页面显示正确的用户信息和菜单

### 3. 用户管理功能测试

#### 测试步骤
1. 以管理员身份登录
2. 进入用户管理页面
3. 测试以下功能：
   - 查看用户列表（分页）
   - 创建新用户
   - 编辑用户信息
   - 启用/禁用用户
   - 重置用户密码
   - 删除用户

#### 预期结果
- 用户列表正确显示，分页功能正常
- 创建用户成功，列表自动刷新
- 编辑用户信息成功保存
- 用户状态切换正常
- 密码重置成功
- 删除用户成功（管理员账号不能删除）

#### 验证点
- 检查 `/api/users/v1/page` 响应格式包含分页信息
- 所有操作的响应格式统一为 `{code: 0, data: {...}, message: "..."}`
- 错误情况返回正确的错误码和消息

### 4. 密码修改功能测试

#### 测试步骤
1. 登录后进入个人设置
2. 修改密码
3. 使用新密码重新登录

#### 预期结果
- 密码修改成功
- 使用新密码可以正常登录
- 旧密码无法登录

#### 验证点
- 检查 `/api/users/v1/change-password` 请求
- 如果前端发送加密密码，确认包含clientId
- 后端正确解密并更新密码

### 5. 错误处理测试

#### 测试场景
1. 使用错误的用户名或密码登录
2. 使用过期的clientId登录
3. 访问无权限的接口
4. 在token过期后访问需要认证的接口

#### 预期结果
- 错误的用户名或密码：返回401错误，提示"用户名或密码错误"
- 过期的clientId：返回400错误，提示"密钥已过期"
- 无权限访问：返回403错误，提示"权限不足"
- token过期：返回401错误，前端自动跳转到登录页

#### 验证点
- 所有错误响应格式统一
- HTTP状态码正确
- 错误消息清晰明确
- 前端正确处理各种错误情况

## 安全测试

### 测试项目
1. 密钥管理
   - 验证私钥不会暴露给前端
   - 验证密钥有过期时间
   - 验证过期密钥会被清理

2. 密码安全
   - 验证密码在传输过程中是加密的
   - 验证解密后的明文密码不会被记录
   - 验证密码验证失败不会泄露用户信息

3. Token安全
   - 验证token有过期时间
   - 验证过期token会被拒绝
   - 验证token包含必要的用户信息

## 常见问题排查

### 问题1：RSA加密失败
**可能原因：**
- 公钥格式不正确
- 浏览器不支持Web Crypto API
- node-forge库未正确加载

**解决方法：**
- 检查后端返回的公钥格式
- 检查浏览器控制台错误信息
- 确认node-forge依赖已安装

### 问题2：密码解密失败
**可能原因：**
- clientId不匹配
- 密钥已过期
- 加密算法不一致

**解决方法：**
- 确认前端发送的clientId与后端存储的一致
- 检查密钥是否在有效期内
- 确认前后端使用相同的加密算法（RSA-OAEP with SHA-256）

### 问题3：登录后无法获取用户信息
**可能原因：**
- token未正确存储
- token格式不正确
- 认证中间件配置错误

**解决方法：**
- 检查LocalStorage中的token
- 确认请求头包含正确的Authorization字段
- 检查后端认证中间件日志

### 问题4：分页数据显示异常
**可能原因：**
- 分页参数传递错误
- 响应格式不匹配
- 前端分页组件配置错误

**解决方法：**
- 检查请求参数currentPage和pageSize
- 确认响应包含所有必需的分页字段
- 检查前端分页组件的配置
